# 📦 竞拍之王 BidKing（网页版）

Steam《BidKing》玩法的单机网页复刻：**仓储盲盒拍卖**。
你是拍卖场里的收藏家，与 3 名 AI 对手争夺一个个神秘仓库——看颜色线索、听真实提示、
倍率出价、碾压成交、开仓见分晓。

## 运行

```bash
# 方式一：直接双击 index.html（零依赖，离线可玩）
# 方式二：本地服务器
cd bidking
python -m http.server 8082
# 浏览器打开 http://localhost:8082
```

## 玩法（还原自 Steam BidKing 的核心机制）

1. **选场交门票**：低场 → 别墅 → 船运 → 隐秘，门票越来越贵、格数越来越多、出货率越来越高
2. **每回合一个盲盒仓**：格子总数 20~120 **可见**，颜色 = 表面品质线索（白绿蓝紫金红）
3. **物品占格隐藏**：每件物品占 1~16 格（大红大件占大格），开仓才见分晓；约 7% 陷阱（表面光鲜实为仿品）、5% 惊喜
4. **倍率出价**：每轮选当前价的倍数（1.05×~1.5×）；**碾压成交**——最高 ≥ 第二高 × 碾压线（逐轮递减：×1.35 → ×1.40 → ×1.10）直接成交；AI 有出价上限，你可以随时更高倍率梭哈截胡
5. **每轮出价后随机真实提示**：金红格数量、陷阱警告、大件数量……全部基于仓内真实内容，仔细听
6. **开仓逐件揭示**：品质越高鉴定越久（大红转 5 秒），实时累计价值，可**一键跳过**
7. **5 回合后按总资产排名**，赚不回门票就是亏

## 角色技能（选 1）

| 角色 | 技能 |
|------|------|
| 🔍 检索眼·贝拉 | 每局 2 次：直接揭示 2 件物品的真实内容 |
| 📐 数量师·维克托 | 每局 2 次：显示本仓金/红格数量（测陷阱） |
| 🗺️ 透视师·伊森 | 每局 1 次：标出可疑格（🔴表面光鲜实为垃圾 / 🟢暗藏惊喜） |
| 🎯 截胡王·拉文 | 每局 1 次：本轮 AI 无上限且碾压线再降；被动碾压线 -10% |

## 素材说明

- **物品图片**：24 张真实藏品照片，来自 Openverse 检索的 CC 授权图源（Flickr 博物馆/档案馆为主），已下载到 `img/` 本地离线使用；来源见 `img/manifest.json`，可重下：`node img/download.js`（需可访问 `live.staticflickr.com`）
- **音效**：Web Audio 实时合成
- **界面**：纯 CSS（丝绒拍卖厅、彩色格子、开箱翻卡）

## 文件

```
img/              24 张 CC 授权物品图片 + 清单
```
