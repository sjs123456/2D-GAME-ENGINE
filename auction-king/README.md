# 🔨 竞拍之王 Auction King

网页版拍卖师模拟游戏：判断买家心理价位，在恰当的时机落锤成交。

## 运行

```bash
# 方式一：直接双击 index.html（零依赖，离线可玩）
# 方式二：本地服务器
cd auction-king
python -m http.server 8081
# 浏览器打开 http://localhost:8081
```

## 玩法

- 物品上架后，现场买家（AI）会轮流举手出价
- 每件物品都有**期望成交区间**（价格牌下方有提示）
- 在合适的时机点击 **落锤** 按钮或按 **空格** 成交
- 卖太低 → 亏本；价格冲太高 → 无人接盘，**流拍**（扣金币）
- 共 3 关 × 每关 5 件物品，按总得分评定 1~3 星
- `M` 键开关音效；进度自动存档（localStorage）

## 素材说明

全部素材由代码程序化生成，**零外部依赖**：

| 素材 | 方案 |
|------|------|
| 物品 / 买家形象 | 系统 emoji（🏺💍👴🤵…）+ CSS 光效、聚光灯、幕布、浮层动画 |
| 背景 / 舞台 | CSS 渐变 + 动画（丝绒幕布、摆动聚光灯、落锤震屏） |
| 音效 | Web Audio API 实时合成（出价叮、落锤咚、成交和弦、流拍） |

如需替换为真实图片：在 `js/items.js` 的物品数据中加 `image` 字段即可（相对路径或 URL），游戏会自动用图片替代 emoji 展示：

```js
{ name: '青花缠枝瓷瓶', image: 'img/vase.png', base: 500, sweetLo: 700, sweetHi: 950, desc: '…' }
```
