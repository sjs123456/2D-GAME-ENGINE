# ⛏ 方块大陆 VoxelCraft（重写版 v2）

网页版《我的世界》风格 3D 沙盒建造游戏。**全部素材（地形/纹理/音效）由代码实时程序化生成**，无任何外部素材依赖。

## 运行

```bash
# 本地服务器（推荐）
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 当前会话服务器已在 **http://localhost:8080** 运行。

## 技术要点（v2 重写）

- **64×64×40 体素世界**：噪声地形（山丘/海洋/沙滩/草地）+ 树 + 洞穴 + 煤/铁矿石
- **渲染**：`InstancedMesh` 实例化 + **Three.js 内置 `BoxGeometry`**（winding/UV 由引擎保证，杜绝手写几何错误）；水面用独立 `PlaneGeometry` 实例，半透明
- **纹理**：16×16 Canvas 逐像素程序化绘制（草/土/石/木/叶/沙/水/矿石/基岩）
- **物理**：重力、跳跃、游泳、飞行、AABB 碰撞（二分精确回退）
- **双视角**：第三人称跟随（镜头自动避障）+ 第一人称
- **交互**：DDA 体素射线，6 格内挖/放；准星悬停提示
- **音效**：WebAudio 程序化合成
- **存档**：localStorage 自动保存（60s + 关闭时），可继续上次世界
- 实测：Chrome 150，稳定 165+ FPS，无黑色渲染瑕疵
